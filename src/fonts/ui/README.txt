Interface fonts offered in Settings -> Font (v1.3.1). Each is a glyph subset
(Basic Latin, Latin-1, Bengali U+0980-09FF with Bengali digits and the danda,
general punctuation, a few arrows) converted to WOFF2 with fontTools/pyftsubset.
Variable fonts were limited to wght 400-700 and wdth 100. Every file is
licensed under the SIL Open Font License 1.1; the licence text of each family is
included here (OFL-*.txt). None of the families is renamed because none declares
a Reserved Font Name that applies to these files. The app never loads remote fonts.

Hind Siliguri        (Indian Type Foundry)         hind-siliguri-400/700.woff2
Noto Sans Bengali    (Noto Project Authors)        noto-sans-bengali.woff2 (variable)
Noto Serif Bengali   (Noto Project Authors)        noto-serif-bengali.woff2 (variable)
Anek Bangla          (Anek Project Authors)        anek-bangla.woff2 (variable)
Baloo Da 2           (Baloo 2 Project Authors)     baloo-da-2-400/700.woff2 (static instances)
Tiro Bangla          (Indigo Project Authors)      tiro-bangla-400.woff2
Galada               (Hornus, Minet, Bruce et al.) galada-400.woff2
Atma                 (Atma Project Authors)        atma-400/700.woff2
Mina                 (Mina Project Authors)        mina-400/700.woff2
The default "System" option uses Segoe UI Variable / Segoe UI / Nirmala UI and
needs no file.
