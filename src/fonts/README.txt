alhamdulillah-aref-ruqaa.woff is a glyph subset of Aref Ruqaa Bold (version 1.003) by
The Aref Ruqaa Project Authors (https://github.com/alif-type/aref-ruqaa), licensed
under the SIL Open Font License 1.1 (see ArefRuqaa-OFL.txt). It contains only the
glyphs and OpenType shaping features needed to render the phrase "الحمد لله" for the
daily completion reward (about 10 KB). It is bundled locally; the app never loads
remote fonts. It replaces the Amiri subset used up to v1.3.0.
Created with: pyftsubset ArefRuqaa-Bold.ttf --text="الحمد لله"
--layout-features='*' --flavor=woff --name-IDs='*' --no-hinting
